הגדרת Google

  1. צור Programmable Search Engine והגדר אתרים לחיפוש לפי הצורך.

הערה: Google Custom Search JSON API כפוף לזמינות, מכסות ותנאי Google. בלי הגדרות אלה, התוסף יציע לפתוח את תוצאות Google הרגילות ולא יטען אותן כאילו הן תוצאות API.
